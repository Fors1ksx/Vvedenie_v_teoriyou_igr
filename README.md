# Тренажёр по теории игр

Локальное веб-приложение с пятью заданиями курса «Введение в теорию игр»:

1. Графический метод (игра m×2)
2. Сокращение матрицы доминированием
3. Метод определителей
4. Симплекс-метод
5. Метод Брауна–Робинсон

Чистые HTML, CSS и JavaScript — без сборки и без бэкенда. Задания можно проходить в любом порядке, неверные проверки считаются как ошибки, прогресс хранится в localStorage браузера.

## Запуск

```
python -m http.server 8000
```

Затем открыть http://localhost:8000.

## Самопроверка решателей

```
node tests/run-selftest.js
```

То же самое в браузере: http://localhost:8000/test.html. Проверяются эталоны 4 варианта и корректность всех пяти вариантов.

## Структура

- `index.html`, `css/style.css` — страница и стили
- `js/solvers.js` — решатели: графический метод, доминирование, метод определителей, симплекс-метод, Браун–Робинсон
- `js/variants.js` — варианты: 4 вар задан вручную, остальные генерируются и проверяются решателями
- `js/step1.js` … `js/step5.js` — окна заданий
- `js/ui.js` — окна, диалоги, калькулятор, хранилище
- `js/main.js` — главный экран
- `js/selftest.js`, `tests/run-selftest.js`, `test.html` — самопроверка
